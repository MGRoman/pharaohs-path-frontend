# Pharaoh's Path: Egyptian Journeys

Создай полностью адаптивный, современный и визуально премиальный многостраничный frontend-сайт туристического агентства **Pharaoh's Path**, специализирующегося на путешествиях по Египту.

Это **ЭТАП 1 проекта**.

Главная задача текущего этапа — создать максимально качественный, цельный и реалистичный **frontend premium travel-сервиса** с полноценными пользовательскими сценариями.

На этом этапе **НЕ создавай backend, базу данных, реальную оплату, CRM или внешние интеграции**. Используй только mock/static data.

---

# 1. КОНЦЕПЦИЯ БРЕНДА

Название:

**Pharaoh's Path**

Позиционирование:

**Премиальные путешествия по Египту — от древних пирамид до коралловых рифов Красного моря.**

Сайт должен ощущаться как luxury boutique travel brand.

Визуальное настроение:

* luxury travel;
* premium hospitality;
* cinematic;
* editorial;
* sophisticated;
* minimalistic;
* современный египетский стиль;
* много свободного пространства;
* крупная выразительная типографика;
* высококачественные фотографии;
* аккуратные micro-interactions.

Не превращай сайт в «египетскую тематику» с большим количеством иероглифов, золотых рамок и декоративных элементов.

Древнеегипетская эстетика должна быть **тонким визуальным слоем**, а не главным украшением.

**«Я хочу оказаться там».**

* whitespace;
* композицию;
* контраст;
* аккуратные золотые акценты;
